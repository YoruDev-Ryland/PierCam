## Added

- **Post the night to Discord.** Paste a channel's webhook URL into Config → Discord and PierCam posts a still every so often through the night, and the finished timelapse when the session ends. It needs no bot and no account — the URL comes from Discord's *Server Settings → Integrations → Webhooks → Copy Webhook URL*.
  - Set how often stills go up (hourly by default), whether the timelapse is posted at all, and the name the posts appear under.
  - Stills carry the night's title, the time, how many frames are in so far, the exposure and gain, and the sky level. They show the same view as the app, including the target marker ring when that is on.
  - **Send this frame** and **Send last night** post on demand, whatever the schedule says.
  - Discord's upload limit depends on the server's boost level, so an oversize video is not simply refused: PierCam re-encodes a smaller copy for the upload and says that is what it is. Your recording is never touched.
  - Nothing PierCam posts ever pings anyone.

## Fixed

- **The target marker no longer throws away a good calibration when it cannot see the sky.** It now checks that the calibration belongs to the camera currently connected — swapping to a different camera used to make it judge one camera's lens against another's sensor — and a calibration is only discarded after two consecutive failed checks, so a single cloudy or roof-blocked look cannot undo it.
- **A quiet roof file is no longer reported as a fault.** These files are written when a roof *moves*, not on a timer, so a weathered-out spell leaves one that is hours or days old with nothing wrong. A file that says CLOSED is now believed however old it is, and only a stale OPEN is treated as broken — the case where the writer may have died while the roof shut.
- The horizon for giving up on the roof file is now a day rather than twelve hours, which was only just longer than a night: a roof opened in the early evening could cross it before dawn and hold recording in the small hours of a clear night.
- A paused player now shows the frame it is parked on after a seek, instead of going blank.

## Changed

- The foot of the Config page is machined like the rest of it: the Target Marker, Discord and Diagnostics rails interlock with the same 45° seams and index tabs as the plates above, and their titles sit clear of the seam above them. Image Tuning and Diagnostics now carry the lifted fill that Site & Roof has.
- Release notes now come from the repository, so a release says what changed rather than linking to a list of commits.

## Upgrading

Run the new installer over 1.4 — your settings and timelapse library are kept. For the portable zip, replace the old folder. Discord posting is off until you switch it on.
