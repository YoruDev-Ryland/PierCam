## Added

- **Remote access API.** Let other apps — a dashboard on another machine, over Tailscale or a LAN — read from PierCam. Config → **08 / NET → REMOTE ACCESS**, off by default.
  - **The live frame** as a JPEG, at the size and quality asked for. Polling is cheap: an unchanged frame answers "not modified" with nothing to download.
  - **Status:** what PierCam is doing, the camera, the roof or safety monitor, the next session.
  - **The recorded nights**, with posters, and each video streamable with seeking — so an app can show the list and only stream a night when someone plays it.
  - **Its own documentation**, served at `/api/v1/docs` (and as Markdown at `/api/v1/docs.md`), always matching the version that serves it. The same reference is in the repository as [docs/api.md](https://github.com/YoruDev-Ryland/PierCam/blob/main/docs/api.md).
  - **Read-only:** nothing can be changed through it — no settings, no camera, no recordings — and the live frame always has the blur mask applied.
  - Choose **this PC only** or **other machines too**, the port (1890 by default), and optionally **require an access key**, sent as an `X-Api-Key` header or `?key=` on the URL. The panel lists the addresses to use, Tailscale's first.
  - Needs no administrator rights. The first time it is switched on, Windows may ask whether to let PierCam through the firewall — allow it on the network your other app uses.

## Upgrading

Run the new installer over 1.13 — your settings and timelapse library are kept.
